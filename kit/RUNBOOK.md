# Brand Gambit weekly run — rules

Read this before building an issue. `issues/01/issue.json` is the reference example.

## Content
- Audience: founders and senior decision-makers in India (Bengaluru first). Not designers.
- Lead story: one Indian founder/business win where trust did the selling. Expand it into a real piece (~450–600 words): setup, the real problem, the mechanism (what the diagram shows), "What this means for your brand" with exactly 3 steps, one closing line.
- Two short takes (60–80 words each) from the week's other picks, each with its stat, one-line trust point and source link.
- Every number must appear in the linked source. Say "company says" / "company-reported" where it is. Never add numbers from memory. Never reuse a story already used in an earlier issue.
- Voice: direct, plain, founder-to-founder. No hashtags, no "game-changer", minimal em dashes, no hype adjectives. Sign off "Kushi", title "Brand designer, Kushi Grafixx". `intro_note` is empty after Issue 01.

## Images (1200px wide, saved as JPEG q86)
- `cover.jpg` from `templates/cover.html`: one big number (BIG, `<small>` for the unit), BIG_SIZE 200–260 so it fits, STIPPLE_X placed behind the end of the number, KICKER "Company · City · Event", SUPPORT one line, SUBJECT_TAG 3–6 words.
- `diagram.jpg`: `templates/diagram-mapping.html` (customer doubt → brand answer, 3 rows) or `templates/diagram-stat.html` (one number vs a benchmark). If neither fits, write a new template in `templates/` that uses `base.css` and the same rules.
- Brand rules: Outfit only, never a mono or second typeface (small labels are Outfit 500 uppercase, tracked), paper #F5F4F0, ink #0C0C0C, Kushi Red #E8001D for ONE focal element only (3–8% of the frame), full-pill capsules, 10px card radius, no gradients/glows on the logo, no flat colour stripes, logo at true aspect ratio.
- Always open each rendered image and check: no overflow, no clipped text, no single-word last lines, nothing touching the edges.
