# The Brand Gambit — assets

Public image hosting and the build kit for **The Brand Gambit**, the weekly newsletter by [Kushi Grafixx](https://kushigrafixx.in).

- `issues/NN/` — each issue's `issue.json` (content) plus `cover.jpg` and `diagram.jpg`
- `kit/` — templates, brand assets and scripts that render the images and build the assembly email

Images are served from `https://raw.githubusercontent.com/kushi-grafixx/brand-gambit-assets/main/issues/NN/<file>`.
